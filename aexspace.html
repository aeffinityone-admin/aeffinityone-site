AEXSpace

Build worlds. Organize ideas.

AEXSpace is a digital creator workspace for story worlds, character profiles, scenes, visual references, audio, workspace notes, ideas, and invite-based team access.

AEXSpace Terms Privacy

Creator Workspace Tools

Workspaces

Create project spaces with cover art, a project description, invite codes, and organized sections for the world being built.

Story Description

Save the premise, plot, direction, book, show, world, or idea that anchors the workspace.

Characters

Build character profiles with age, biography, personality, roles, powers, visual references, theme music, and voice references.

Scene Management

Save scene titles, descriptions, reference images, and scene notes for books, animation, games, or other story formats.

Audio Vault

Upload MP3, WAV, and voice notes so audio can be attached to characters or used as project reference material.

Notes & Ideas

Separate confirmed workspace notes from quick ideas so creative thoughts stay organized without becoming clutter.

Team Permissions

Invite collaborators with workspace-specific access while protecting owner-created content from unwanted deletion.
